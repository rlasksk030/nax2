# ⌨️ 우리 반 타자 성장대회 웹앱

한컴타자에서 잰 **타수 / 정확도**만 입력하면, **처음의 나와 지금의 나**를 비교해
얼마나 성장했는지 계산해 주는 Google Apps Script 웹앱입니다.

> 이 대회는 **"누가 가장 빠른가"가 아니라 "누가 처음의 자기보다 가장 많이 성장했는가"** 를 봅니다.
> 그래서 학생 화면에는 다른 학생의 점수나 순위가 **전혀 보이지 않습니다.**
> 전체 순위와 시상 결과는 **선생님 관리 화면**에서만 볼 수 있습니다.

- 웹앱에는 타자 연습·측정 기능이 없습니다. 측정은 한컴타자에서 하고, 이 웹앱에는 **기록만 입력**합니다.
- 데이터베이스는 **Google 스프레드시트 한 장**이면 충분합니다. 서버가 필요 없습니다.

---

## 1. 처음 설치하기 (약 10분)

Apps Script를 처음 써 보는 선생님도 순서대로 따라 하시면 됩니다.

### ① Google 스프레드시트 만들기
1. [sheets.new](https://sheets.new) 에 접속하면 새 스프레드시트가 만들어집니다.
2. 왼쪽 위 파일 이름을 `타자 성장대회` 처럼 알아보기 쉽게 바꿉니다.

### ② Apps Script 열기
1. 상단 메뉴에서 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 새 탭에 코드 편집기가 열리고 `Code.gs` 파일에 예시 코드가 들어 있습니다.

### ③ 코드 붙여넣기 (파일 6개)
`Code.gs` 안의 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 붙여넣습니다.
그다음 **왼쪽 파일 목록의 `+` → HTML** 을 눌러 아래 5개 파일을 차례로 만듭니다.
(파일 이름을 넣을 때 `.html` 은 자동으로 붙으므로 **이름만** 입력하세요.)

| 만들 파일 이름 | 붙여넣을 내용 |
|---|---|
| `index` | `index.html` |
| `style` | `style.html` |
| `script` | `script.html` |
| `admin` | `admin.html` |
| `adminScript` | `adminScript.html` |

> 파일 이름이 하나라도 다르면 화면이 열리지 않습니다. 철자를 꼭 확인해주세요.

마지막으로 **저장(💾 또는 Ctrl+S)** 합니다.

### ④ 관리자 비밀번호 바꾸기
`Code.gs` 맨 위의 이 줄을 우리 반에서 쓸 비밀번호로 바꿉니다.

```javascript
const ADMIN_PASSWORD = "1234";   // ← 꼭 바꿔주세요!
```

### ⑤ `initializeSheets()` 실행하기 (시트 자동 생성)
1. 편집기 위쪽 함수 선택 상자에서 **`initializeSheets`** 를 고릅니다.
2. **▶ 실행** 을 누릅니다.
3. 처음 한 번은 권한 승인 창이 뜹니다.
   **권한 검토 → 내 Google 계정 선택 → (경고 화면이 나오면) 고급 → '프로젝트 이름'(안전하지 않음)으로 이동 → 허용**
   순서로 진행하면 됩니다. 내가 만든 스크립트가 내 시트를 여는 것이라 안전합니다.
4. 스프레드시트로 돌아가면 **`학생명단`** 과 **`기록`** 시트가 만들어져 있습니다.

### ⑥ 학생명단 수정하기
`학생명단` 시트에 있는 샘플 5명을 지우고 우리 반 학생을 넣습니다.

| A(번호) | B(이름) |
|---|---|
| 1 | 김하늘 |
| 2 | 이준서 |
| … | … |

- **B열(이름)만 정확하면 됩니다.** 번호는 비워도 동작합니다.
- **같은 이름이 두 명 있으면 안 됩니다.** 동명이인은 `김하늘(1)`, `김하늘(2)` 처럼 구분해주세요.
- 학생을 나중에 추가·삭제해도 됩니다. 웹앱이 매번 명단을 다시 읽습니다.

### ⑦ 웹 앱으로 배포하기
1. Apps Script 편집기 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
2. 톱니바퀴(⚙️) → **웹 앱** 을 선택합니다.
3. 설명은 `1차 배포` 등 자유롭게 적습니다.

### ⑧ 실행 사용자 · 접근 권한 설정
| 항목 | 설정값 | 이유 |
|---|---|---|
| **다음 사용자로 실행** | **나(선생님 계정)** | 학생에게 시트 편집 권한을 주지 않아도 기록이 저장됩니다. |
| **액세스 권한이 있는 사용자** | **링크가 있는 모든 사용자** | 학생이 로그인 없이 바로 쓸 수 있습니다. |

> 학교 계정(구글 워크스페이스)을 학생이 모두 쓰고 있다면
> **'○○학교의 모든 사용자'** 로 두는 편이 더 안전합니다.

**배포** 를 누르면 `https://script.google.com/macros/s/..../exec` 형태의 **웹 앱 URL** 이 나옵니다.

### ⑨ 학생에게 URL 공유하기
- 클래스룸 공지, 학급 홈페이지, 단축 URL, QR 코드 등으로 알려주면 됩니다.
- 학생은 **접속 → 이름 선택 → 기록 입력** 만 하면 끝입니다.

> **코드를 고친 뒤에는** 반드시 **배포 → 배포 관리 → ✏️(편집) → 버전: 새 버전 → 배포** 를 해야
> 학생 화면에 반영됩니다. (URL은 그대로 유지됩니다.)

## 2. 사용 방법

> 화면은 **컴퓨터실 PC 기준**으로 만들었습니다.
> 학생 메뉴 3개, 3회 입력칸, 처음/최종 기록 비교가 **한 화면에 나란히** 보이므로 스크롤이 거의 없습니다.
> 태블릿·휴대폰으로 열면 자동으로 세로 배치로 바뀌어 레이아웃이 깨지지 않습니다.

### 학생
1. 웹앱 접속 → 내 이름 선택 → **들어가기**
2. 🌱 **기초 기록 등록** — 한컴타자에서 같은 조건으로 **3회** 측정한 타수/정확도 입력
3. 🏁 **최종 기록 등록** — 대회 마지막 날 같은 방식으로 **3회** 측정해 입력
4. 📈 **나의 성장 결과** — 처음 기록과 최종 기록, 성장점수, 격려 문구 확인

> 기초·최종 기록은 **각각 한 번만** 등록할 수 있습니다.
> 잘못 넣었다면 학생이 고칠 수 없고, **선생님 관리 화면에서만** 수정할 수 있습니다.

### 선생님
관리 화면에 들어가는 방법은 두 가지입니다. **둘 다 비밀번호가 필요합니다.**

1. 학생 화면 첫 페이지 맨 아래 **[선생님용 관리 화면]** 링크
2. 웹 앱 주소 뒤에 **`?admin=1`** 붙이기 — 비밀번호 화면이 바로 열립니다
   예) `https://script.google.com/macros/s/…/exec?admin=1`
   (선생님 즐겨찾기에 이 주소를 저장해 두면 편합니다.)

| 기능 | 설명 |
|---|---|
| 🏅 시상 결과 | 성장왕 / 폭풍 성장상 / 정확 타자상 / 번개 타자상 자동 선정 |
| 📋 전체 기록 보기 | 13개 항목 + 순위를 표로 확인 (성장점수 높은 순 정렬) |
| 🧮 순위 다시 계산 | 기록이 바뀌었을 때 전체 점수·순위 재계산 |
| ✏️ 수정 | 학생의 3회 기록을 고치면 중간값·점수가 자동으로 다시 계산됨 |
| 🗑 삭제 | 확인창 후 해당 학생의 기록 삭제 (명단에는 그대로 남음) |
| ⬇️ CSV 다운로드 | 전체 결과를 엑셀에서 열 수 있는 CSV로 저장 |

> 브라우저가 다운로드를 막는 환경이라면 **[📄 CSV 내용 보기]** 로 내용을 복사해
> 메모장에 붙여넣고 `결과.csv` 로 저장하면 됩니다.
>
> 스프레드시트에서 **⌨️ 타자 성장대회** 메뉴로도 초기화·재계산을 할 수 있습니다.

## 3. 성장점수는 이렇게 계산합니다 (100점 만점)

### ① 기초/최종 기록 = 3회 중 **타수의 중간값**
| 회차 | 타수 | 정확도 |
|---|---|---|
| 1회 | 184 | 94% |
| 2회 | 191 | 96% |
| 3회 | 176 | 95% |

→ 타수를 크기순으로 놓으면 176 · **184** · 191 이므로 **기초 기록 = 184타 / 94%**
(정확도는 중간값으로 뽑힌 그 회차의 값을 그대로 씁니다.)

**평균을 쓰지 않는 이유:** 한 번 실수하거나 일부러 천천히 친 기록의 영향을 줄이기 위해서입니다.

### ② 성장 지표
| 항목 | 계산식 | 예시 |
|---|---|---|
| 타수 증가량 | 최종 타수 − 기초 타수 | 247 − 184 = **+63타** |
| 타수 향상률 | (최종 − 기초) ÷ 기초 × 100 | 63 ÷ 184 × 100 = **34.2%** |
| 정확도 변화 | 최종 정확도 − 기초 정확도 | 97 − 94 = **+3%p** |

### ③ 점수 배분
| 요소 | 배점 | 계산 방법 |
|---|---|---|
| 타수 증가량 | 50점 | 학생 증가량 ÷ **반 최고 증가량** × 50 (증가량이 0 이하면 0점) |
| 타수 향상률 | 40점 | 학생 향상률 ÷ **반 최고 향상률** × 40 (향상률이 0 이하면 0점) |
| 최종 정확도 | 10점 | 아래 표 |

| 최종 정확도 | 점수 |
|---|---|
| 98% 이상 | 10점 |
| 96 ~ 97.9% | 8점 |
| 94 ~ 95.9% | 6점 |
| 92 ~ 93.9% | 4점 |
| 90 ~ 91.9% | 2점 |
| 90% 미만 | 0점 |

**성장점수 = 증가량 점수 + 향상률 점수 + 정확도 점수** (최대 100점, 소수점 첫째 자리까지)

> 증가량과 향상률을 **함께** 쓰기 때문에, 처음 타수가 낮은 학생만 유리해지지 않습니다.
> 반 전체를 기준으로 정규화하므로 **학생 기록이 추가/수정될 때마다 모든 점수와 순위가 다시 계산됩니다.**

### ④ 동점 처리
성장점수가 같으면 **① 최종 정확도 → ② 타수 증가량 → ③ 향상률** 이 높은 학생이 앞 순위입니다.
네 가지가 모두 같으면 공동 순위가 됩니다.

## 4. 파일 구성

| 파일 | 역할 |
|---|---|
| `Code.gs` | 서버 로직 (시트 읽기/쓰기, 중간값·성장점수 계산, 검증, 관리자 기능) |
| `index.html` | 화면 뼈대 (학생 화면 전체) |
| `style.html` | 디자인 (파스텔 색상, 둥근 카드 / **PC 화면 기준**, 좁은 화면도 자동 대응) |
| `script.html` | 학생 화면 동작 |
| `admin.html` | 교사 관리 화면 뼈대 |
| `adminScript.html` | 교사 관리 화면 동작 |
| `tests/` | 개발용 검증 도구 (Apps Script에는 올리지 않아도 됩니다) |

### `기록` 시트 (웹앱이 자동으로 채웁니다)
| 열 | 항목 | 열 | 항목 |
|---|---|---|---|
| A | 학생명 | N | 최종3 타수 |
| B | 기초1 타수 | O | 최종3 정확도 |
| C | 기초1 정확도 | P | **최종 타수(중간값)** |
| D | 기초2 타수 | Q | **최종 정확도** |
| E | 기초2 정확도 | R | 증가 타수 |
| F | 기초3 타수 | S | 향상률(%) |
| G | 기초3 정확도 | T | 정확도 변화(%p) |
| H | **기초 타수(중간값)** | U | 증가량 점수 |
| I | **기초 정확도** | V | 향상률 점수 |
| J | 최종1 타수 | W | 정확도 점수 |
| K | 최종1 정확도 | X | **성장점수** |
| L | 최종2 타수 | Y | 최종 순위 |
| M | 최종2 정확도 | Z | 마지막 수정시간 |

> R~Y열은 계산 결과라서 **웹앱이 다시 계산할 때마다 덮어씁니다.**
> 기록을 손으로 고치실 때는 B~G(기초 3회), J~O(최종 3회)를 고친 뒤
> 관리 화면에서 **[순위 다시 계산]** 을 눌러주세요.
> (관리 화면의 **[수정]** 버튼을 쓰면 중간값까지 자동으로 다시 계산되므로 더 편합니다.)

## 6. 입력 규칙

| 항목 | 규칙 | 잘못 입력하면 |
|---|---|---|
| 타수 | 0 ~ 1000 사이의 정수 | `2회 타수는 0~1000 사이의 숫자로 입력해주세요. (소수점 없이)` |
| 정확도 | 0 ~ 100 (소수점 가능) | `정확도는 0~100 사이의 숫자로 입력해주세요.` |
| 빈칸 | 6칸을 모두 채워야 저장 | `1회 타수가 비어 있어요. 3회 기록을 모두 입력해주세요.` |

검사는 **학생 화면과 서버 양쪽에서** 모두 실행되므로, 화면을 우회해도 잘못된 값은 저장되지 않습니다.

## 7. 자주 묻는 질문

**Q. 학생이 다른 친구 이름으로 기록을 넣으면 어떡하나요?**
이름을 고르는 방식이라 교실 안의 신뢰를 전제로 합니다. 다만 **이미 등록된 기록은 아무도 덮어쓸 수 없고**,
수정·삭제는 비밀번호가 필요한 관리 화면에서만 가능합니다. 잘못 들어간 기록은 선생님이 고치시면 됩니다.
학교 계정을 쓰신다면 배포할 때 접근 권한을 **'○○학교의 모든 사용자'** 로 좁히는 것을 권합니다.

**Q. 학생이 실수로 기록을 잘못 넣었어요.**
관리 화면 → 해당 학생 **[수정]** → 3회 기록을 고치고 저장하면 중간값·성장점수·순위가 자동으로 다시 계산됩니다.
한 구간(기초 또는 최종)의 6칸을 **모두 비우면** '등록 안 함' 상태로 되돌아가 학생이 다시 입력할 수 있습니다.

**Q. 대회 도중에 전학생이 왔어요.**
`학생명단` 시트에 이름만 추가하면 바로 웹앱에 나타납니다.

**Q. 관리 화면에 기록이 하나도 안 보여요.**
표에는 **`학생명단` 시트의 학생**이 모두 나오고, 아직 입력하지 않은 칸은 `-` 로 표시됩니다. 다음을 확인해주세요.
1. 주소 뒤에 `?admin=1` 을 붙였거나 [선생님용 관리 화면]으로 들어가 **비밀번호를 입력**했는지 (학생 화면에는 기록이 보이지 않습니다)
2. `학생명단` 시트 **B열**에 이름이 들어 있는지 (비어 있으면 "학생명단 시트에 학생을 추가해주세요."가 표시됩니다)
3. 학생이 아직 기록을 입력하지 않았다면 이름만 나오고 나머지는 `-` 가 맞습니다
4. 코드를 고친 뒤 **새 버전으로 다시 배포**했는지

**Q. 점수가 이상해요.**
관리 화면 **[순위 다시 계산]** 을 눌러보세요. 반 전체를 기준으로 정규화하므로,
새 학생이 크게 성장하면 다른 학생의 증가량·향상률 점수는 자연스럽게 조정됩니다.

**Q. "스프레드시트를 찾을 수 없습니다" 라고 나와요.**
스프레드시트의 **확장 프로그램 → Apps Script** 로 만든 스크립트가 아닐 수 있습니다.
그럴 때는 `Code.gs` 위쪽 `SPREADSHEET_ID` 에 시트 주소의 `/d/` 와 `/edit` 사이 값을 넣어주세요.

**Q. 화면 위에 빨간 경고가 떠요 / "Cannot read properties of null" 오류가 나요.**
HTML 파일 중 하나가 **비어 있거나 이름이 다르다**는 뜻입니다. 웹앱이 스스로 어떤 파일이 문제인지 알려주니,
경고에 적힌 이름(`index` `style` `script` `admin` `adminScript`)의 파일을 Apps Script 편집기에서 열어
내용이 들어 있는지, 이름의 대소문자가 맞는지 확인한 뒤 **새 버전으로 다시 배포**해주세요.
(`adminScript` 는 대문자 S 입니다.)

**Q. 화면이 안 열려요 / 예전 화면이 나와요.**
코드를 고친 뒤 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 를 하셨는지 확인해주세요.

## 8. 개발자용 (선택)

Node.js가 있으면 배포 전에 계산 로직과 화면을 검증할 수 있습니다.

```bash
cd typing-growth-contest

# 계산 로직 검증 (Code.gs 원본을 그대로 실행합니다)
node tests/run_tests.js

# 배포 전에 브라우저에서 화면을 미리 보기 (가짜 데이터로 동작)
node tests/build_preview.js
# → tests/preview.html 을 브라우저로 열면 됩니다
```

`tests/run_tests.js` 는 다음을 확인합니다 (총 183개).

- 3회 중 **타수 중간값**이 정확히 선택되는지 / 그 회차의 **정확도**가 함께 선택되는지 (기초·최종 모두)
- 증가량 · 향상률 · 정확도 변화 계산값
- **0으로 나누기** 방지 (기초 타수 0, 성장한 학생이 아무도 없는 반, 학생 1명뿐인 반, 빈 명단)
- 증가량 점수(50) · 향상률 점수(40) 정규화, 정확도 점수(10) 구간
- 성장점수가 **100점을 넘지 않는지**
- 기록이 추가·수정·삭제될 때 **전체 점수와 순위가 다시 계산되는지**
- 동점자 규칙 (정확도 → 증가량 → 향상률, 완전 동일 시 공동 순위)
- **중복 등록 차단**, 명단에 없는 이름 차단, 학생이 남의 기록을 덮어쓸 수 없음
- 비밀번호 없이 관리자 기능(조회·수정·삭제·CSV) 호출 차단
- 입력 검증 (빈칸 / 음수 / 1000타 초과 / 100% 초과 / 문자·소수점 타수)
