이게 무엇인가요?

학생들이 한컴타자에서 잰 기록(타수·정확도)을 입력하면, 처음보다 얼마나 늘었는지를 자동으로 계산해 주는 우리 반 전용 웹사이트입니다.

  • 학생은 인터넷 주소만 열면 됩니다. 앱 설치도, 로그인도 필요 없습니다.
  • 기록은 선생님의 구글 스프레드시트에 자동으로 저장됩니다.
  • 학생에게는 자기 기록만 보입니다. 전체 순위와 시상 결과는 선생님만 봅니다.
  • 타자 연습·측정 기능은 없습니다. 측정은 한컴타자에서 하고, 여기에는 숫자만 입력합니다.
✅ 다 만들면 이렇게 됩니다

선생님이 학생에게 주소 하나를 알려주면 → 학생이 이름을 고르고 기록을 넣고 → 선생님은 관리 화면에서 반 전체 순위와 시상 결과를 봅니다.

1

준비물 확인하기 2분

구글 계정 학교 계정(@school.kr 등)이나 개인 지메일 아무거나 괜찮습니다. 선생님 계정으로 로그인되어 있어야 합니다.
인터넷 브라우저 크롬(Chrome)을 권합니다. 엣지(Edge)도 됩니다.
파일 6개 같이 받은 코드 폴더 안에 있습니다. Code.gs · index.html · style.html · script.html · admin.html · adminScript.html
💡 파일을 여는 방법

파일을 더블클릭하면 브라우저가 열려 버릴 수 있습니다. 그러면 글자를 복사하기 어렵습니다.
파일 위에서 마우스 오른쪽 버튼 → 연결 프로그램 → 메모장으로 여세요. (메모장에서 Ctrl + A 전체 선택 → Ctrl + C 복사)

2

구글 스프레드시트 만들기 1분

학생들의 기록이 저장될 표(엑셀 같은 것)를 먼저 만듭니다.

  1. 브라우저 주소창에 sheets.new 라고 치고 Enter.
  2. 빈 표가 하나 만들어집니다. 이게 우리 반 기록 창고입니다.
  3. 왼쪽 위 제목 없는 스프레드시트를 눌러 타자 성장대회처럼 이름을 바꿉니다.
💡 저장은 안 눌러도 됩니다

구글 스프레드시트는 자동으로 저장됩니다. 저장 버튼을 찾지 마세요.

새 탭이 열리고 Code.gs 라는 파일에 이런 글자가 몇 줄 들어 있습니다. 이것이 우리가 코드를 넣을 곳입니다.

🤔 Apps Script가 뭔가요?

구글이 무료로 주는 간단한 프로그램 작성 공간입니다. 우리는 코드를 직접 쓰지 않고 붙여넣기만 합니다.

4

파일 6개 붙여넣기 7분 · 가장 중요

① 첫 번째 파일 (Code.gs)

  1. 편집기 가운데 있는 글자를 모두 지웁니다. (글자 아무 곳이나 누르고 Ctrl + A → Delete)
  2. 받은 파일 중 Code.gs를 메모장으로 열어 전체 복사 (Ctrl + A → Ctrl + C)
  3. 편집기에 붙여넣기 (Ctrl + V)
  4. 저장 (Ctrl + S)

② 나머지 5개 (HTML 파일)

왼쪽 파일 목록 옆의 ＋ 를 누르고 HTML을 고릅니다. 이름을 넣는 칸이 나옵니다.

왼쪽 파일 목록
파일 ＋
스크립트
HTML
⚠️ 여기서 실수가 가장 많습니다

이름을 넣을 때 .html은 빼고 이름만 넣으세요. .html은 구글이 알아서 붙입니다.

대문자·소문자도 정확히 같아야 합니다. 특히 adminScript는 S가 대문자입니다.

Apps Script에 넣을 이름붙여넣을 파일
indexindex.html
stylestyle.html
scriptscript.html
adminadmin.html

새 파일을 만들면 안에 <!DOCTYPE html>로 시작하는 글자가 몇 줄 들어 있습니다. 그것도 모두 지우고 받은 파일 내용을 붙여넣으세요. 그리고 저장 (Ctrl + S).

✅ 다 하면 왼쪽 목록이 이렇게 됩니다

Code.gs · index.html · style.html · script.html · admin.html · adminScript.html

6개가 모두 있고, 각 파일을 눌렀을 때 안에 글자가 가득 차 있으면 성공입니다.

5

비밀번호 바꾸기 1분

Code.gs 파일을 누르고, 맨 위에서 이 줄을 찾으세요. (스크롤을 조금 내리면 보입니다)

Code.gs 위쪽
const ADMIN_PASSWORD = "1234";
const REQUIRE_SCREENSHOT = false;
  • ADMIN_PASSWORD — 선생님 관리 화면에 들어갈 비밀번호입니다. "1234" 를 우리 반에서 쓸 비밀번호로 바꾸세요. 큰따옴표 " 는 지우지 마세요.
  • REQUIRE_SCREENSHOT — true 로 바꾸면 학생이 결과 화면 캡처를 3장 모두 올려야만 저장됩니다. 그냥 두면 캡처는 선택입니다.

바꾼 뒤 Ctrl + S 로 저장하세요.

시트 만들기 · 권한 허용 3분

기록을 저장할 표를 프로그램이 자동으로 만들어 줍니다.

  1. 편집기 위쪽 가운데에 함수를 고르는 칸이 있습니다. 거기서 initializeSheets 를 고릅니다.
  2. 바로 옆 ▶ 실행을 누릅니다.
편집기 위쪽
▶ 실행 🐞 디버그 initializeSheets ▾
⚠️ 무서운 경고 화면이 나옵니다 — 정상입니다

처음 한 번만 나옵니다. 아래 순서대로 누르세요.

① 권한 검토 → ② 내 구글 계정 선택 → ③ "Google에서 확인하지 않은 앱" 화면이 나오면 왼쪽 아래 고급 → ④ '(프로젝트 이름)'(안전하지 않음)으로 이동 → ⑤ 허용

선생님이 직접 만든 것이라 구글이 아직 모르는 앱이라 그렇습니다. 내 시트를 내가 여는 것이니 안전합니다.

💡 무슨 권한을 왜 주나요?

스프레드시트 — 학생 기록을 표에 적기 위해서입니다.
구글 드라이브 — 학생이 올린 캡처 사진을 선생님 드라이브의 타자 성장대회 캡처 폴더에 저장하기 위해서입니다.

✅ 확인하는 법

스프레드시트 탭으로 돌아가 보세요. 아래쪽에 학생명단, 기록 두 개의 시트가 새로 생겨 있으면 성공입니다.

우리 반 학생 이름 넣기 3분

아래쪽 학생명단 시트를 누릅니다. 샘플 학생 5명이 들어 있습니다. 지우고 우리 반 학생을 넣으세요.

A열 (번호)B열 (이름)
1김하늘
2이준서
……
  • B열(이름)만 정확하면 됩니다. 번호는 비워도 됩니다.
  • 같은 이름이 두 명 있으면 안 됩니다. 동명이인은 김하늘(1), 김하늘(2) 처럼 구분해 주세요.
  • 전학생이 오면 줄만 추가하면 됩니다. 다시 설치할 필요 없습니다.
⚠️ 첫 줄(번호 / 이름)은 지우지 마세요

1행은 제목 줄입니다. 학생 이름은 2행부터 넣으세요.

8

인터넷 주소 만들기 (배포) 3분

학생들이 들어올 인터넷 주소를 만드는 단계입니다. Apps Script 탭으로 돌아가세요.

  1. 오른쪽 위 파란 배포 버튼 → 새 배포
  2. 왼쪽 톱니바퀴(⚙️) → 웹 앱 선택
  3. 아래 두 칸을 반드시 이렇게 맞춥니다
칸 이름고를 것
다음 사용자로 실행나 (선생님 계정)
액세스 권한이 있는 사용자링크가 있는 모든 사용자

배포를 누르면 주소가 나옵니다. …/exec 로 끝나는 주소가 학생에게 줄 진짜 주소입니다. 복사해서 어딘가에 적어두세요.

💡 학교 계정을 학생도 쓴다면

"액세스 권한"을 ○○학교의 모든 사용자로 좁히면 더 안전합니다. 단, 학생이 학교 계정으로 로그인되어 있어야 열립니다.

⚠️ 앞으로 코드를 고칠 때마다 꼭

배포 → 배포 관리 → ✏️(연필) → 버전: 새 버전 → 배포
이걸 하지 않으면 학생 화면은 예전 그대로입니다. 주소는 바뀌지 않습니다.

9

직접 해보고 학생에게 알려주기 5분

  1. 만든 주소를 열어봅니다. ⌨️ 우리 반 타자 성장대회 화면이 나오면 성공입니다.
  2. 학생 한 명 이름을 골라 기초 기록(예: 100 / 90, 110 / 92, 105 / 91)을 넣어봅니다.
  3. 이어서 최종 기록도 넣어보고 성장 결과가 나오는지 봅니다.
  4. 첫 화면 맨 아래 [선생님용 관리 화면] → 아까 정한 비밀번호 → 표가 나오는지 봅니다.
  5. 연습으로 넣은 기록은 관리 화면에서 [삭제] 해서 깨끗하게 만들어 두세요.
  6. 이제 학생에게 주소를 알려주면 끝입니다. (클래스룸 공지, 학급 홈페이지, QR 코드 등)
💡 선생님만 쓰는 빠른 주소

주소 뒤에 ?admin=1 을 붙이면 바로 비밀번호 화면이 열립니다. 이 주소를 즐겨찾기에 넣어두면 편합니다. (물론 비밀번호는 그대로 필요합니다)

10

대회 진행하기

언제무엇을
대회 첫날 학생 안내문을 나눠주고 규칙을 설명합니다. 한컴타자로 3번 재서 🌱 기초 기록을 등록하게 합니다. (회차마다 결과 화면 캡처도 올릴 수 있습니다)
대회 기간 학생들은 평소처럼 연습합니다. 선생님은 가끔 관리 화면에서 등록 현황만 확인하면 됩니다.
마지막 날 같은 방법으로 3번 재서 🏁 최종 기록을 등록하게 합니다. 학생은 등록하자마자 자기 성장 결과를 봅니다.
시상 관리 화면 위쪽 🏅 시상 결과에 네 개의 상이 자동으로 뽑혀 있습니다. 필요하면 CSV 다운로드로 결과를 엑셀에 저장하세요.
💡 학생이 잘못 입력했다면

기록은 한 번만 등록할 수 있습니다. 학생은 고칠 수 없습니다.
관리 화면에서 그 학생 줄의 [수정]을 눌러 고쳐 주세요. 한 구간(기초 또는 최종)의 6칸을 모두 비우면 그 학생이 다시 입력할 수 있습니다.

11

문제가 생겼을 때

이런 증상이렇게 하세요
화면 위에 빨간 경고가 뜬다
"Apps Script 파일이 비어 있거나 이름이 다릅니다"		 경고에 적힌 파일 이름을 확인하세요. 그 파일이 비어 있거나 이름이 틀린 것입니다. 다시 붙여넣고 새 버전으로 배포하세요.
Cannot read properties of null 같은 영어 오류 붙여넣은 코드가 예전 것입니다. 6개 파일을 모두 다시 붙여넣고 새 버전으로 배포하세요.
관리 화면에 기록이 하나도 안 보인다 표 위의 진단 줄을 보세요. 학생명단 0명 → 명단이 비어 있습니다. 기록 시트 0행 → 아직 아무도 입력하지 않았습니다.
"스프레드시트를 찾을 수 없습니다" 표에서 확장 프로그램 → Apps Script로 만들지 않았을 때 납니다. 2번 단계부터 다시 하세요.
학생 화면이 예전 그대로다 배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포를 하지 않은 것입니다.
캡처 사진이 저장되지 않는다 드라이브 권한이 아직 없는 것입니다. 6번 단계(initializeSheets 실행)를 다시 해서 권한을 허용하세요. 타자 기록 자체는 정상 저장됩니다.
점수가 이상하다 관리 화면 [순위 다시 계산]을 눌러보세요. 점수는 반 전체 기준이라, 새 학생이 크게 성장하면 다른 학생 점수도 자연스럽게 조정됩니다.
💡 웹앱 없이 상태만 보고 싶을 때

스프레드시트 위쪽 ⌨️ 타자 성장대회 → ③ 기록 상태 점검을 누르면 학생 수와 기록 수가 바로 나옵니다. (메뉴가 안 보이면 스프레드시트를 새로고침하세요)

12

마지막 점검표

  • 스프레드시트에 학생명단, 기록 시트가 있다
  • Apps Script에 파일이 6개 있고 모두 내용이 들어 있다
  • ADMIN_PASSWORD를 내가 정한 비밀번호로 바꿨다
  • 학생명단 B열에 우리 반 학생 이름이 들어 있다 (중복 없음)
  • 배포할 때 실행: 나 / 접근: 링크가 있는 모든 사용자로 했다
  • …/exec 주소를 열어 화면이 정상적으로 나온다
  • 관리 화면에 비밀번호로 들어가 표가 보인다
  • 연습으로 넣은 기록을 삭제했다
  • 학생에게 나눠줄 안내문을 인쇄했다

이제 우리 반 타자 성장대회를 시작할 수 있습니다! 🌱
